## Friends, profiles and messages (registered players only)

- **Data** (Prisma migration `20261026000000_friends`): `Friendship` (one row per pair, ids stored sorted, `status` pending/accepted, `requestedBy`), `UserBlock`, `UserMute`, `DirectMessage` (last 200 per pair kept), `FriendCode` (personal invite code, 12 chars). No foreign keys: `DELETE /api/me` calls `onDeleted` -> `FriendStore.purge`. After changing the schema regenerate the Prisma client in the **running** dev server too (`docker compose exec server sh -c "cd /app/apps/server && pnpm exec prisma generate"` then restart it), or friends routes fail with `Cannot read properties of undefined (reading 'findMany')`.
- **Server**: `social/friendStore.ts` (`FriendStore`: memory + Prisma), `http/friendRoutes.ts` (all REST, all need a registered token, else 403 `Register to use friends` FRI-101): `GET /api/friends` (friends with online/room/unread/muted, incoming + outgoing requests, my code, blocked), `POST /api/friends/request {userId|code}` (asking back after being asked = friends; caps `FRIENDS_MAX` 200 / `PENDING_MAX` 50), `/api/friends/:id/accept|decline` (decline also cancels my own), `DELETE /api/friends/:id`, `POST /api/friends/code/regenerate`, `GET /api/users/search?q=` (nickname only, never e-mail; min 2 chars, max 10, hides blockers), `GET /api/users/:id/profile` (stats, friend state, muted), `POST /api/users/:id/block|unblock|mute|unmute`, `GET|POST /api/messages/:id` (+ `/read`; friends only, one line <= 300 chars, profanity masked, flood limit burst 5 then 1 per 2 s), `POST /api/friends/:id/invite {roomCode}` (needs a lobby I am really in). **Block** removes the friendship and stops requests, messages and search/profile both ways; **mute** keeps the friendship and stores messages but gives no push, banner, unread badge or invite. Realtime (reusing `userChannel`): `social:update` (refetch the list), `dm:message`, `game:invite` (`ServerToClientEvents`). Errors FRI-101..111 (FRI-103 "Player not found" is the existing ADM-102). Tests: `http/friends.test.ts`, `e2e/tests/friends.spec.ts` (needs `MAIL_MODE=log`: registers through the dev mailbox).
- **Web** (`apps/web/src/friends`): `FriendsProvider` (mounted in `Shell` around everything: owns the list, refetches on `social:update`, the sheets, the DM / invite banner `dm-banner` / `invite-banner` with a Join button, and the `?friend=CODE` invite link), `FriendsButton` (`friends-button`, badge `friends-badge` = unread + open requests) placed **next to the leaderboard button** on Home and in the Lobby toolbar and in the in-game bars (`TopBar` and Yatzy's own header), `FriendsSheet` (in a lobby its header has an **Invite** button, `friends-share`, left of the close button: the phone's share sheet or copies the join link, `lib/shareRoom.ts`; tabs Friends / Requests / Find with search `friends-search`, my invite link and Copy / New link), `ProfileCard` (no title row: the close X sits level with the name and its subtitle, the handle right above; a name too long for the room scrolls slowly (`Marquee`); Invite is blue; tap a player's picture in the lobby crew, chat, leaderboard or results: stats, Add friend / Message / Invite to my lobby / Mute / Remove / Block with confirm), `Thread` (`thread-input`, `thread-send`, `dm-mine`, `dm-theirs`), `ProfileTap` (wraps a picture; plain for guests, computers and myself), REST wrappers in `lib/friendsApi.ts`, socket hooks `socialTick` / `onDm` / `onInvite` in `lib/socket.ts`. Guests see `friends-guest` ("Register an account...").

## Friends sheet (detents)

The friends list opens in `DetentSheet` (`components/DetentSheet.tsx`): it swipes in to half the screen; drag the grabber / title (or anywhere on it while it is at half) up to full height, down to half or away. It follows the finger, resists a little past the top, lands where the flick was heading (position + 250 ms of velocity), settles with an iOS-style curve (`cubic-bezier(.32,.72,0,1)`, 420 ms) and the page dims with it. At full height the list scrolls. Tapping the grabber toggles half / full. No motion with reduced motion.
