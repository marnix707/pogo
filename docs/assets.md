## Art and sound assets (apps/web/src/assets, inbox: apps/web/src/unsorted)

- **Inbox workflow:** the user drops new or redrawn art/sfx into `apps/web/src/unsorted/` (any layout, e.g. a whole export folder). Claude sorts the files into `src/assets/` as below, replaces the old versions of anything redrawn, wires them up if they are used, updates this section, and **empties `unsorted/` again** (only `.gitkeep` stays). Delete the `*:Zone.Identifier` files Windows adds when copying.
- `assets/sprites/`: pixel-art SVGs exported from the artist's "POGO SVG" pack: `cards/` (52 faces `AS.svg`..`KC.svg` = rank A,2-10,J,Q,K + S/H/D/C, `joker.svg`, `back.svg`, `suits/` big + `-mini`), `characters/` (king, queen, jack, joker, 24x30), `dice/` (`die-1..6.svg`, 16x16, colour = value), `brand/` (frog, frog-pogo, pogo-stick, wordmarks, lockup, key art, boing-lines), `animation/` (front view) and `animation-side/` (side view): frames/fx/spritesheet + JSON timing. `README.md` there explains the pixel grid (scale by whole numbers, `image-rendering: pixelated`), `manifest.json` lists every file with size, `pogo-assets.json` holds the pixel rows + palette, `palette.css` the colours.
- `assets/icons/`: the app icon set (favicon, apple-touch, 192/512 + maskable, 1024). `LogoMark` imports `icon.svg`; the live icons in `public/` need fixed URLs for the manifest, so they are copies (`icon-512-maskable.png` = `public/icon-maskable-512.png`): copy again and bump `sw.js` `VERSION` when the icon is redrawn.
- `assets/sfx/`: `sfx_frog_croak_single.mp3` (every frog jump in the intro), `sfx_pogo_stick.mp3` (every pogo bounce) via `lib/sfx.ts` (`playSfx`, respects the sound setting; browsers silence it until the first tap), `sfx_frog_croak_multiple.mp3` (unused so far). The in-game beeps are still synthesized in `lib/sound.ts`.
- `assets/sprites/colour-cards/` (Last Card deck, 56 files), `brand/logos/` (game picker logos), `assets/icons/icon-rounded.svg` (rounded tile for in-app use, not used yet). The artist's exports arrive as zips next to `assets/` (`pogo-svg.zip` = the whole SVG export, `pogo-assets.zip` = the older brand kit); they are gitignored, extract and sort them as above, then the zip can go. When icons change, copy to `public/` too (`icon-192`, `icon-512`, `apple-touch-icon`, `icon-maskable-512` <- `icon-512-maskable`, `favicon.svg`, `favicon.ico`) and bump `sw.js` `VERSION`.
- Used so far: cards, dice, wordmark, animation frames/fx, icon, two sfx. Not yet: characters (king/queen/jack/joker art), key art, lockup, boing lines, mini suits, joker, side spritesheets. Import with Vite (`import url from '../assets/sprites/dice/die-1.svg'`) so files get fingerprinted for the service worker.
