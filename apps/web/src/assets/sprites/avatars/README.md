# POGO avatars

11 player avatars in the POGO pixel style: fox, cat, panda, frog (Pogo), owl, octopus, unicorn, penguin, lion, koala and bee.

- `avatar-<name>.svg`: transparent **22×22** pixel art, centred, with the navy `#101628` outline and a 1px drop shadow.
- `avatars.json`: the display order and file names.
- Show them at a whole-number scale, 3× (66px) or 4× (88px), with `image-rendering: pixelated;`.
- Picker style that matches the game: navy `#233049` tiles with a 2px `#101628` border and rounded corners; the selected avatar gets a white `#ffffff` border.
